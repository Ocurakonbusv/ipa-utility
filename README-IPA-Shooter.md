# IPA Shooter

KSignの動作確認用に作った、タップ操作のシンプルなiPhone向けシューティングゲームです。画面を指でドラッグして自機を左右に動かし、自動で発射される弾でピンク色の敵を倒します。

## IPAについて

このプロジェクトは、Appleの署名資格情報をリポジトリへ含めず、GitHub ActionsのmacOS環境で**署名前のIPA**を生成する構成です。iPhoneへ入れるには、おくら自身が所有する正規の署名方法でKSignなどを使って再署名する必要があります。

## ビルド

GitHub Actionsの`Build unsigned IPA`を手動実行すると、`IPA-Shooter-unsigned.ipa`がアーティファクトとして出力されます。署名証明書、秘密鍵、Apple ID、プロビジョニングプロファイルはこのリポジトリに保存しません。

## 操作

画面を左右にドラッグすると自機が移動します。敵に接触するとゲームオーバーになり、「もう一度プレイ」で再開できます。
