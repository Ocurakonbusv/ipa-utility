# IPA Utility

iPhoneでIPAファイル、証明書、プロビジョニングプロファイルを扱うための独自Webプロトタイプです。KSignの静的解析で確認した「入力」「署名準備」「進捗」「インストール開始」という機能の考え方を参考にしていますが、コード、画像、秘密鍵、アプリ内部資産は流用していません。

## 現在できること

IPA、`.p12` / `.pfx`証明書、`.mobileprovision`プロファイルをブラウザ上で選択できます。ファイルの拡張子を検証し、入力状態を表示し、書き込み準備の確認ダイアログと進捗表示を行います。また、HTTPSの`manifest.plist` URLを入力すると、iOSの`itms-services`インストール開始リンクへ接続できます。

## 現在できないこと

この公開静的版にはLinux署名ワーカーが接続されていないため、実際にIPAへ再署名する処理は実行しません。Apple ID、p12パスワード、秘密鍵、プロビジョニングプロファイルをサーバーへ送信・保存する機能もありません。実署名を接続する場合は、ユーザー自身が所有する証明書・プロファイルを前提に、一時ファイルを処理後に破棄するバックエンドが必要です。

無料Apple Personal Teamを使う場合は、App ID・端末・アプリ数・プロビジョニングの期限などの制限があります。署名済みアプリをiPhoneで使うには、署名条件、Bundle ID、端末登録、HTTPS配布、Developer Modeなどが一致する必要があります。

## 安全上の注意

Apple IDのパスワード、確認コード、秘密鍵、証明書ファイルをチャットや公開リポジトリへ置かないでください。公開リポジトリに秘密情報をコミットしないこと、ユーザー自身が権利を持つIPAだけを扱うことを前提にしています。

## ライセンスと位置づけ

このリポジトリは個人用の独自プロトタイプです。KSignのコードや資産を複製したものではありません。実署名と配布を接続する前に、Appleの最新の開発者規約・配布条件を確認してください。
